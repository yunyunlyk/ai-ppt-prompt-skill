# 图生视频模板

```text
你是资深视频导演与MG动效师。请仔细观察我上传的【图片描述】，精准识别其
视觉风格与氛围，并反推一条用于AI视频生成的结构化提示词。

目标：将静态图转化为契合原图氛围的动态PPT背景。

要求：
氛围匹配：动效设计需完全贴合原图的风格（如科技感、活泼风、复古风等），
强化原有的情感表达。
视觉分层：将画面元素拆解分层，设计独立、平滑的局部微动
输出格式：仅输出最终的结构化视频生成提示词（包含镜头语言、元素动态、
光影氛围），无需多余解释，无需生成视频。
```

## 用的时候怎么填

把 `【图片描述】` 换成对图的客观描述，不要评价。至少写清四件事：

1. 画面里有什么（主体 / 背景 / 文字区）。
2. 风格（科技 / 复古 / 杂志 / 极简）。
3. 光与色（冷蓝霓虹、暖金侧光、清晨雾气）。
4. 静态图的留白在哪一侧（给标题留位）。

## 输出形态

一条提示词，三段结构：**镜头语言**（缓推 / 平移 / 轻微视差）→ **元素动态**（逐层写：背景雾流动、主体不动、光斑飘移）→ **光影氛围**（明暗呼吸、色温变化、颗粒）。不要输出分镜表，也不要在同一层里叠两种运动。
