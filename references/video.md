# 动效与图生视频

两条路：**工具内直接给静态图加动效**（快、可控），或**反推一条视频提示词**交给视频模型（慢、成片感强）。先看用途选路。

## 1 静态图 → 动效镜头（工具内生成）

适合「封面 / 章节页要一点活气」，成品是几秒的循环片段。四个输入，缺一个就变成随机瞎动：

| 输入 | 填什么 | 例 |
| --- | --- | --- |
| 提示词 | 只写运动与光影，不写故事 | 镜头从左向右推进，水面波纹流动，云层快速飘动，光影变化，营造电影感 |
| 运动方向 | 左 / 右 / 上 / 下 / 推进 / 拉远 | 推进 |
| 镜头参数 | 推进、摇移、景深，0–100% | 推进 80% / 摇移 40% / 景深 60% |
| 关键帧 | 起点帧与落点帧 | 首帧静止，尾帧略近 |

输出是逐帧连续画面（1–5 帧序列），能直接当视频片段用。

判断该不该做：静态图出现「缺动感、画面平淡、构图僵硬」三种症状时，动效补的是**活气**，不是故事。别指望它救一张构图错的图——那要先换图。

## 2 图生视频提示词（反推）

给静态图写提示词，让视频模型生成契合原图氛围的动态背景：

```text
你是资深视频导演与MG动效师。请仔细观察我上传的【图片描述】，精准识别其
视觉风格与氛围，并反推一条用于AI视频生成的结构化提示词。

目标：将静态图转化为契合原图氛围的动态PPT背景。

要求：
氛围匹配：动效设计需完全贴合原图的风格（如科技感、活泼风、复古风等），
强化原有的情感表达。
视觉分层：将画面元素拆解分层，设计独立、平滑的局部微动
输出格式：仅输出最终的结构化视频生成提示词（包含镜头语言、元素动态、
光影氛围），无需多余解释，无需生成视频。
```

`【图片描述】` 换成客观描述，至少写清四件事：画面里有什么（主体 / 背景 / 文字区）、风格、光与色、留白在哪一侧。

输出形态是一条提示词三段结构：**镜头语言**（缓推 / 平移 / 轻微视差）→ **元素动态**（逐层写：背景雾流动、主体不动、光斑飘移）→ **光影氛围**（明暗呼吸、色温、颗粒）。同一层里不要叠两种运动。

## 3 用在哪：克制

动效只在封面、章节页、单个重点页出现。三种情况直接不用：

- 正文页：会跟阅读抢注意力。
- 一页里想动多个元素：动一整屏等于没动。
- 这一页要念数据、念结论：观众眼睛该在文字上。

判断标准可以借用配图那条：**动效也不能占用放字的地方**。
