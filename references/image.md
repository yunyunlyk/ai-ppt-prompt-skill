# 配图类模板

## 1 按标题反推配图

```text
# 任务描述
你作为一位具备极高审美的设计师。我正在为PPT封面寻找配图，我会提供给你
PPT封面中的标题文案，请根据以下规则生成3组纯文本格式的AI生图提示词，
注意，提示词中不要增加参数描述。

你需要遵循以下步骤：
首先，深度理解用户提供的PPT标题，理解信息的主题，提取1-2个核心关键词；
然后，联想与关键词强关联的主体视觉画面，一定要把抽象的概念，转换成一个具体的画面；
最后，输出3组纯文本格式的AI生图提示词。

# 务必遵循以下要求
1. 采用「真实摄影拍摄风格」，不能使用插画、超现实、微距等风格描述。
2. 构图规则：主体仅占据画面1/3面积（优先右侧或底部布局），
   2/3留白空间，每一组提示词中都需要强制添加，不能省略。
3. 主体元素数量：一个画面中只能有一个核心的主体视觉元素，不能堆砌一堆元素。
4. 在将关键词转换为具体画面时，不要过度延伸，一定要找到符合用户认知中
   最贴切的画面，比如提到新能源，可能想到的就是光伏、风电等场景，
   而非碳排放监测设备、植树造林等。
5. 输出的提示词务必遵循【风格关键词 + 主体画面描述 + 场景描述（适当增加
   场景描述，避免画面单调）+ 构图逻辑】的结构。

# 输出前检查
- 是否遵循了思考的步骤；
- 是否遵循了所有的输出要求。
```

为什么要求留白 2/3：封面标题要压在空的那一侧，图本身不能有主体抢位。这条是所有配图里最容易被忽略、也最容易毁版的一条。

## 2 人物双重曝光（改图指令）

多图输入（图一风格底、图二剪影素材、图三人物）。整段照抄，改的只是主体描述：

```text
保持图一的双重曝光影像风格，将图三的人物替换到图一中，并去掉图一中所有的
文字信息和吊灯。图三人物作为画面主体，前景清晰。

双重曝光融合：在他的正面形象之上，对图二进行处理，变成一个更大、半透明的
深棕色男性侧脸剪影，剪影轮廓柔和，叠加在图三后，与正面人物的轮廓自然交织，
形成「一人双像」的视觉效果。将照片尺寸改为16:9，图片左侧留白，用来写文字。

主色调：以暖金色、深棕、纯黑为主，辅以柔和的米白高光，整体呈现出复古剧院的
奢华感与神秘感。

质感：背景是朦胧的暖金色纹理，带有细腻的光斑和颗粒感，仿佛剧院幕布或旧照片
的质感，光线柔和，营造出梦幻、怀旧的氛围。
```

替换点：性别 / 主色调 / 留白方向（左侧写文字则留左，反之留右）/ 场景气质（复古剧院可换成演播厅、旧厂房、图书馆）。

## 3 使用顺序

先按 1 出 3 组提示词 → 用户挑一组生成封面 → 需要改人物或换风格时用 2 的指令做二次编辑。别把两步合成一条提示词，风格会飘。
